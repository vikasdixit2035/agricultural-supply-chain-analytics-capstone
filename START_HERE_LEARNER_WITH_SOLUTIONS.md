# START HERE — Learner + Complete Solutions

This package intentionally contains **both the learner assignment and the complete reference solution**.

## Recommended learning sequence
1. Read `01_Project_Brief/Agricultural_Supply_Chain_Analytics_Learner_Brief.pdf`.
2. Review `02_Data/Data_Dictionary_KPI_Catalog.xlsx`.
3. Work only from `02_Data/Raw/` first.
4. Build PostgreSQL tables with `03_SQL/01_Create_Schema.sql` and load files with `03_SQL/00_Load_Data.sql`.
5. Attempt the 50 questions in `03_SQL/03_Business_Questions_50.txt`.
6. Complete `04_Python/Agricultural_Supply_Chain_Analytics_Learner.ipynb`.
7. Build the Power BI report from the supplied model/DAX/blueprint.
8. Complete `08_Submission_Templates/Supply_Chain_Opportunity_Model_Learner.xlsx` and the executive memo.
9. Only then open the solution files below.

## Important note about Power BI
A native Microsoft `.pbix` binary is not included. The package supplies the cleaned model inputs, DAX, theme, page architecture, validated outputs and reference report needed to build the PBIX in Power BI Desktop.
